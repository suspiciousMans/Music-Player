This is a regular website

The floating player in the corner is <music-widget>, dropped in with a single script tag. It plays the fixed playlist the site owner defined in playlist.json — visitors can play/pause/skip, but can't change what's queued. A notification slides out from the corner every time the track changes. 

<script
  src="/music-widget.js"
  data-playlist="/playlist.json"
  data-position="bottom-right"></script>
